# DEMO - HospitalTech

## 1. Objetivo

El objetivo de esta demostración es comprobar el funcionamiento de las
principales funcionalidades desarrolladas en el sistema HospitalTech.

Durante la demostración se verificará:

- Registro de usuarios.
- Inicio de sesión.
- Autenticación mediante JWT.
- Creación de tickets.
- Clasificación automática.
- Determinación de prioridad.
- Generación de recomendaciones.
- Consulta de tickets.
- Ejecución de pruebas automatizadas.

---

## 2. Ejecución del sistema

Para iniciar el backend se ejecuta:

```bash
uvicorn app.main:app --reload
```
