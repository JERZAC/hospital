# Definición del problema - HospitalTech

## 1. Situación actual

En un entorno hospitalario se utilizan diferentes equipos informáticos,
sistemas, aplicaciones y servicios de red que son necesarios para el
funcionamiento de las diferentes áreas.

Cuando se presenta un problema tecnológico, el personal puede reportarlo
sin una clasificación uniforme, dificultando determinar el tipo de
incidente, su prioridad y la acción que debe realizar el personal de
soporte.

## 2. Problema identificado

El principal problema es la falta de un sistema centralizado para
registrar y organizar los incidentes de soporte técnico.

Los problemas pueden estar relacionados con:

- Redes.
- Hardware.
- Software.
- Cuentas de usuario.
- Otros problemas tecnológicos.

La falta de clasificación puede ocasionar que incidentes importantes
no sean atendidos con la prioridad adecuada.

## 3. Necesidad

Se necesita una herramienta que permita registrar los incidentes,
clasificarlos y proporcionar información que ayude al personal de
soporte a atenderlos.

## 4. Solución propuesta

Se propone desarrollar HospitalTech, una aplicación web de soporte
técnico hospitalario.

El sistema permite:

- Registrar usuarios.
- Iniciar sesión.
- Crear tickets.
- Clasificar automáticamente los tickets.
- Determinar la prioridad.
- Generar recomendaciones.
- Consultar tickets registrados.

## 5. Objetivo general

Desarrollar una aplicación web que permita gestionar incidentes de
soporte técnico hospitalario mediante el registro, clasificación,
priorización y seguimiento de tickets.

## 6. Objetivos específicos

- Implementar registro y autenticación de usuarios.
- Implementar gestión de tickets.
- Clasificar automáticamente los incidentes.
- Determinar la prioridad de los incidentes.
- Generar recomendaciones para la atención.
- Almacenar la información en una base de datos.
- Implementar pruebas unitarias y de integración.

## 7. Usuarios

### Usuario del sistema

Puede:

- Registrarse.
- Iniciar sesión.
- Crear tickets.
- Consultar sus tickets.

### Personal de soporte

Utiliza la información de los tickets para identificar:

- Tipo de problema.
- Prioridad.
- Descripción.
- Recomendación de atención.

## 8. Alcance

La versión actual del sistema contempla:

- Autenticación.
- Gestión de usuarios.
- Gestión de tickets.
- Clasificación automática.
- Priorización.
- Recomendaciones.
- Base de datos.
- API REST.
- Interfaz web.
- Pruebas automatizadas.

## 9. Beneficios

HospitalTech permite:

- Centralizar los incidentes.
- Organizar los tickets.
- Identificar problemas prioritarios.
- Facilitar la atención del soporte técnico.
- Mantener información de los incidentes registrados.

## 10. Mejoras futuras

Como futuras mejoras se pueden implementar:

- Roles de usuario.
- Gestión de técnicos.
- Estados de tickets.
- Historial de cambios.
- Notificaciones.
- Dashboard estadístico.
- PostgreSQL.
- Integración con servicios externos.
