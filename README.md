# Sistema de Gestión Hospitalaria

## Descripción

Sistema web desarrollado para gestionar información hospitalaria,
permitiendo administrar pacientes, usuarios y citas médicas.

## Objetivo

Digitalizar y facilitar la gestión de información dentro de un
entorno hospitalario.

## Tecnologías

- Python
- ...
- HTML
- CSS
- JavaScript
- Base de datos
- Git
- GitHub

## Funcionalidades

- Registro de pacientes
- Gestión de citas
- Gestión de usuarios
- Autenticación
- ...

## Arquitectura

El sistema utiliza una arquitectura basada en frontend,
backend y base de datos.

## Instalación

### 1. Clonar repositorio

git clone https://github.com/JERZAC/hospital.git

### 2. Entrar al proyecto

cd hospital

### 3. Crear entorno virtual

python -m venv venv

### 4. Activar entorno virtual

venv\Scripts\activate

### 5. Instalar dependencias

pip install -r requirements.txt

### 6. Ejecutar aplicación

python app.py
